# Dữ liệu

Chép 4 file sau vào thư mục này (lấy từ `drug-interaction-ddinter/data/` hoặc Google Drive của repo đó):

| File | Lấy từ | Nội dung |
|---|---|---|
| `national-drug-ddinter-mapping.csv` | `data/mapping/` | Hoạt chất của từng thuốc Việt Nam (theo số đăng ký) đã map sang DDInter |
| `ddinter_interactions_final.csv` | `data/ddinter/` | 235 nghìn cặp tương tác thuốc – thuốc: mức độ, cơ chế, xử trí |
| `drug_disease_interactions.csv` | `data/ddinter/` | Lưu ý thuốc – bệnh lý |
| `drug_food_interactions.csv` | `data/ddinter/` | Lưu ý thuốc – thức ăn |

Các file CSV không đưa vào git (quá lớn).
